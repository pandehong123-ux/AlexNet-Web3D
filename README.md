# 2016：机器落下的一手

以2016年阿尔法围棋与李世石的五番棋为主线，连接人工智能历史、计算系统、神经网络机制、张量维度、学习反馈与交互实验的离线 Web 展馆。

## 打开
用新版 Chrome / Edge 直接打开 index.html，无需联网。Three.js、样式和程序化图形均在本地包中。若本地文件受设备策略限制，在项目目录运行 `python -m http.server 8766 --bind 127.0.0.1`，访问 http://127.0.0.1:8766/ 。三维部分要求 WebGL 2。

## 六个导航
- 00 崛起前夜：1943—2016六章完整历史，包含20个关键事件。每章呈现问题、方法、能力边界与下一阶段的转折；章节联动四种可旋转、拆解的原理展品，叙事从黑白逐渐进入彩色。
- 01 世纪对局：十九路示意棋盘与可旋转、点击、拆解的计算机架；五局历史讲解与4比1结果。
- 02 决策之核：策略网络、价值网络和树搜索；选择、扩展、评估、回传四阶段单步与循环，查看先验、访问统计与均值。
- 03 维度解剖：保留原十三阶段亚历克斯网络及其数据流、暂停、单步、展开、聚焦和局部计算。另加图像与棋盘简化平面切换、切片选择和平面分离。
- 04 成长系统：加速器拆解、单权重反馈学习、双策略自我对弈原理三组可切换模型。
- 05 实验与边界：原六关完整保留，新增搜索实验入口，讨论概率、专用智能和模拟边界。

地址片段为 #origins、#match、#decision、#dimensions、#growth、#experiments；旧 #history/#model/#labs 兼容。浏览器前进后退和导航左右/首尾键可用。
硬件画布在相关展区之间复用；离开时停止渲染。原网络画布独立且只初始化一次，隐藏时停止传播。进度保留在当前会话，刷新重置。没有亲子或儿童模式。

## 事实和边界
2016年3月9日至15日五番棋，阿尔法围棋4比1获胜；第四局李世石胜。页面讨论第二局37手及第四局78手，但没有导入历史棋谱：上方棋形是合成示例，切换对局只改变历史文字。
硬件为分布式计算与加速器原理模型，不能当作原服务器/显卡复刻。2016年使用人类棋谱与自我对弈的系统和2017年零起点研究在页面中明确区分。
原亚历克斯网络是图像卷积基础对照，不是阿尔法围棋架构。棋盘三个平面简化解释编码思想，不等于原系统完整特征。各层几何、粒子与响应都是展陈编码，不是训练激活或真实耗时。
搜索使用人工先验、合成评估值与简化选择公式，非完整历史算法。训练演示执行单权重平方误差梯度更新，不是强化学习训练。自我对弈模型没有棋力，不执行围棋合法落子、提子或胜负判定。
局部卷积、池化、展平、权重与Softmax实验是真数值运算，全系统不加载模型权重，不进行真实识别或围棋推理。所有来源链接在相应展区列出。

## 开发
`npm ci` → `npm test` → `npm run build`。
- assets/museum.mjs：六区内容与历史/搜索/训练/切片交互。
- assets/museum-scene.mjs：机架棋盘与三组成长系统三维模型。
- assets/museum-data.mjs：事实、路由、示意棋形、搜索与训练状态。
- assets/pages.mjs、labs.mjs：路由与原六关。
- assets/app.mjs、rendering.mjs、content.mjs、science.mjs、network.mjs：原网络及局部计算。
