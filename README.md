# 亚历克斯网络 · 专业计算解剖版

以 Three.js 实现的交互式神经网络架构展品。当前只有专业版：没有儿童卡片、亲子流程、任务或通关系统；未保留儿童版备份。

## 直接运行
使用新版 Chrome / Edge 打开 index.html。script.js 包含 Three.js 与所需后期处理代码，没有 CDN、远程字体和外部模型依赖，可离线运行。
浏览器策略限制本地文件时，在目录执行 `python -m http.server 8766 --bind 127.0.0.1`，访问 http://127.0.0.1:8766/ 。需要 WebGL 2。

## 专业结构
- 输入：三颜色通道分离与像素编码。
- 卷积一：可移动感受野框、卷积核采样、输出特征图。
- 卷积二：多通道特征图、通道扩展和输出响应点。
- 卷积三：空间采样体素响应。
- 卷积四：双分组连接结构。
- 卷积五：深层表征采样体。
- 池化：局部窗口、极值及降采样连接。
- 最终池化与展平：空间采样点重排为向量。
- 全连接：多平面节点体及抽样权重连接。
- 分类和概率：类别分数柱与归一化分布。

## 数据流与镜头
使用 18 路曲线通道束、280 个发光粒子、短线拖尾、到层波前和局部响应叠层。粒子沿计算方向推进，进入层后触发该层响应，不表示真实激活或算力开销。
支持运行、暂停/继续、逐层观察、0.5/1/2 倍速度、展开/收拢、恢复、选层、旋转缩放、全局巡览和单层隔离聚焦。选层也可从底部导航完成。空间键切换运行/暂停，左右键选层，R 恢复；原生控件保留键盘行为。

## 可操作的局部实验
通道切换；5×5 合成输入上的 3×3 边缘/均值算子；池化窗口极值比较；32 个采样数的展平守恒；稠密连接权重调整与整流；四类别稳定 Softmax 归一化。
这些小实验执行真实数值运算，但没有加载 AlexNet 权重，不能识别用户图片。全网特征图和结果是合成示意。四类别实验分布并不是原模型一千类别的完整预测。历史数据、输入尺寸约定和抽样边界在页面“建模与资料”中注明。

## 开发
`npm ci` → `npm test` → `npm run build`。
- assets/app.mjs：场景、交互、镜头、专业面板、实验及生命周期。
- assets/rendering.mjs：分类型三维模型、粒子束和波前。
- assets/content.mjs：各层专业内容、公式、边界。
- assets/science.mjs：真实局部算法、可暂停的播放状态。
- assets/network.mjs：原结构尺寸、顺序与布局。
- tests/browser.cjs：本机 Playwright 验收；移机需调整 Playwright 的本地安装路径。
- output/professional-qa.json 与 output/ 截图为专业版运行证据。

## 验证边界
纯逻辑测试 11 项；浏览器覆盖选层、卷积窗口响应、聚焦、池化、展平、稠密连接、概率归一化、展开、暂停、单步、完成、恢复、历史和手机排版。最终结果以 output/professional-qa.json 为准。
浏览器使用 Edge + SwiftShader 软件渲染，不是实体 GPU 性能测试，也没有宣称所有移动设备均流畅。开启减弱动画可抑制环境动作，但会保留用于解释传播的必要视觉状态。
Three.js MIT 许可见 assets/THREE-LICENSE.txt；论文和比赛链接保留于资料面板。

## Git 版本管理
本项目为独立仓库，默认分支 `main`。首次专业版快照使用标签 `v1.0.0`。
源码、依赖锁文件、文档、测试与 `script.js` 纳入版本管理；保留构建产物是为了克隆后可直接打开页面。修改源码后先重新构建，再一并提交。
`node_modules/`、`output/` 截图与本地验证报告、环境密钥、日志及压缩包不入库；现有本地文件不会因此被删除。浏览器测试结果在其他电脑上需重新生成。

```powershell
# 查看改动
 git status
 git diff
# 开发新功能
 git switch -c feature/功能名称
# 验证并构建
 npm test
 npm run build
# 仅添加本次需要的文件，再提交
 git add assets/app.mjs script.js
 git commit -m "feat: 描述本次功能"
# 查看历史与版本
 git log --oneline --decorate
 git tag
```

当前未配置远程仓库，未执行上传。后续需要发布到 GitHub 时，先确认远程地址、代码授权和待上传内容。

## 三个主导航与实验关卡
默认打开“发展历史”，包含1980至2015及后续影响的七个时间节点与研究来源。
- `#history`：发展历史；`#model`：三维模型；`#labs`：交互实验。地址片段可直达，浏览器前进/后退有效；导航支持左右键与首尾键。
- 模型首次进入时初始化；切换到其他视图停止渲染和传播，不清除选层、展开、镜头与播放位置。首次无法运行 WebGL 时，历史与实验仍可使用。
- 六个实验为通道分离、卷积扫描、最大池化、张量展平、权重调节和概率竞争。必须实际完成操作才能进入下一关，提供错误反馈、提示与本关重试。
- 实验区“在三维模型中查看”会切换到对应层；返回实验页保留本次会话进度。刷新后进度重置，不存储个人数据。
- 完成后显示六项实验记录；支持回看已解锁的关卡与清除全部进度。沿用专业视觉，不包含亲子或卡通模式。

新增模块：assets/pages.mjs 管理视图与关卡界面，assets/labs.mjs 管理纯关卡状态。测试包括 tests/labs.test.mjs、tests/navigation-browser.cjs。导航与关卡验收记录为 output/navigation-qa.json；模型回归记录为 output/professional-qa.json。
