## 体验结果

00的四组原理装置分别表达输入加权、规则推理、分支搜索和数据驱动学习。增加支架、封装、针脚、线圈、曲线管路、透明观察舱、立体节点阵列和反馈通路；调整相机距离与展台，使主体细节更清楚。四组装置统一保留深蓝、青蓝、薄荷青、紫色和金色的材质分区，历史章节切换不再把三维展品强制处理成灰度，避免结构细节在低光下丢失。它们由 `assets/history-models.mjs` 在网页内构造，并非历史实物复刻，也没有声称来自Blender。

## Blender源文件与动画资产

打开 `assets/models/ai-museum-live-v003.blend`，默认进入 `ANIM-01-Compute-System` 场景；切换到 `ANIM-02-Accelerator` 查看加速器。时间轴第1到32帧用于循环预览，第33帧补齐整圈插值。源文件已保存为可正常重开的工程文件，并保留原始任务几何场景。

| 文件 | 三角面 | 字节 | 结构 |
| --- | ---: | ---: | --- |
| `compute-system-live.glb` | 38,236 | 1,622,548 | 六个可选模块，两个独立风扇转子。 |
| `accelerator-live.glb` | 15,396 | 740,816 | 五个可选模块，两个独立风扇转子。 |

风扇叶片和轮毂组成转子，外框、轴承、支架与静态部件分开。每个GLB含一个动画片段和两条转子四元数轨道；完整一圈使用0°、90°、180°、270°、360°关键帧，避免直接首尾插值丢失旋转。局部Y轴是转轴，每个转子具有唯一名称与 `motion/axis/speed/id` 元数据。

循环时间为约1.333秒。速度为可读性而放慢，不输出真实转速、温度或吞吐量。模型维持原工程展品的尺度与PBR材质，不是2016年比赛设备的精确还原。

`engineering-models.mjs` 返回GLB场景与动画片段。交互将可选模块重挂到Three.js场景后，`AnimationMixer(scene)` 通过唯一节点名称绑定转子；使用 `setTime()` 驱动内嵌轨道，同一转子不再额外手动旋转。

## 时间、拆解与资源管理

`createMotionClock()` 仅在展区可见、未暂停且没有减少动态效果时推进累计时间。页面隐藏、切换展区、进入漫游大厅都会停止背景运转；重新显示的第一帧不补跳离开期间的时间。延迟帧的步长上限为0.12秒，避免大幅跳动。

03的局部机制使用受控时间：待机累计时间或当前传播时间。暂停冻结局部响应、扫描窗口、数据包和材质动画；用户主动改变实验参数、相机或可见范围仍可生效。系统启用“减少动态效果”时采用稳定姿态和静态结构。

转子和局部信号保留在各自的可选模块内部，拆解只改变模块位置。跨模块连接在展开或单件检视时隐藏。现有布局继续按真实包围盒、相机方向与屏幕宽高比排布部件，而不是写死拆解坐标。拆分时记录当前视角作为稳定基准，部件在世界坐标中保持固定；部件同时沿观察轴加入浅层错层，避免旋转时不同模块落在同一投影平面。整体和单件视距根据当前相机方向重新计算，恢复视角或再次拆分时会清除旧基准。这样可以完整观察正面、背面、顶部和底部，并保留手机布局的间距。风扇扫掠范围位于静态外框内。

拆分后直接点击画布中的任意零件会自动进入该零件的单件检视，并把视距调整到适合观察的范围；列表选择继续只负责切换讲解内容。单件状态下可以继续拖动环绕、上下观察和滚轮缩放，点击其他零件可以直接切换检视对象。

显存和核心在原资产中共用坐标原点，不能直接用部件原点作数据接口。运行器缓存各部件的局部几何中心，并为左右显存选取独立接口，再转为世界坐标生成数据通路。

切换模型时停止并释放动画播放器绑定，移除特效对象，统一释放几何和材质。原有工程资产与来源证据保持原始哈希；本轮动画使用独立文件。

## 复用与验证

```powershell
npm test
npm run build
node tests/live-exhibits-browser.cjs
node tests/engineering-browser.cjs
node tests/scene-lifecycle-browser.cjs
```

测试通过本机Playwright启动Edge；更换工作站时需调整测试脚本顶部依赖路径。网页运行本身不依赖该路径，也不依赖Python或在线模型服务。

Blender制作脚本为 `tools/blender/build_live_exhibits.py`，脚本开头记录 build、render、validate、sourceqa 等阶段。应使用Blender内置Python执行，普通Python无法提供 `bpy`。制作修改后需要重新导出、检查局部转轴、渲染代表帧、查看接触表，再重新构建网页。

`assets/models/live-manifest.json` 记录文件哈希、节点和面数预算、原始文件保护、四帧渲染与人工目视验收。`assets/provenance/live/` 归档三张接触表及GLB、Three.js播放器、源文件重开等最小证据；其 `evidence-index.json` 使用项目相对路径，迁移后仍可验证哈希。完整本机渲染帧位于 `output/live-blender/`，浏览器截图与专项报告位于 `output/live-browser/`。

本轮验证包括真实GLB解析与重挂播放、轴心固定、静态外框、暂停恢复、显存接口、局部聚焦可见性、13层动画机制、拆解与手机布局。浏览器采用Edge软件渲染，功能结果不能视为手机实机性能评测。

2026年10月23日验收：`npm test` 73项通过，离线构建成功。浏览器运转专项62项、工程拆解228项、生命周期4项、历史19项、原网络17项，共330项检查通过，无页面错误。五份报告随最小证据一同归档，可根据 `evidence-index.json` 验证原始字节。

动画用于表现计算关系。它们不执行完整AlexNet推理、真实围棋搜索或自主对弈，也不构成实时硬件监控；原有局部数值实验仍按其说明执行。
