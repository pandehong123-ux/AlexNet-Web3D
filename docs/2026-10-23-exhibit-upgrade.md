# 三维展馆升级与验收

## 范围

保留六个展区和现有科学边界，提升计算机架及加速器模型，修复拆解遮挡，并补齐角色推演和自由参观。以用户附图四项要求为最低验收线。

1. 定制三维模型：Blender 制作可独立选择的机架、处理器、加速模块、存储、互联、棋盘；导出 GLB 和可编辑源文件。网页支持旋转、缩放、展开、复位、单件检视和部件说明。
2. 互动科普：保留六关局部计算实验、搜索实验和数值训练；新增交互与模型检视互相衔接。
3. 角色或故事推演：研究员、系统工程师、对局分析师各有分阶段任务、选择反馈和复盘。情境为原创教学推演，不冒充历史人员的原话或原始比赛记录。
4. 博物馆参观：顶部进入可行走的三维大厅，六座实体展台、中央生成雕塑、拖动环视、键盘与屏幕移动、墙和展台碰撞、点击进入展区；另有参观地图、分站导览和访问状态。

## 模型与遮挡处理

Blender 使用任务独立场景与集合，不覆盖原始文件。金属边框、托盘、散热鳍片、风扇、封装、接口、固定件和电路纹理按物理功能细分。资产按可选择部件合并网格，限制绘制调用和文件体积。

展开时按相机平面分配不重叠的部件区域，使用各部件包围盒确定间距。机架从板卡中完全移开，棋盘独立保留；模型变化平滑过渡。旋转持续重新分区，用户也可整理视图；单件检视提供无外部遮挡检查。标签使用引线和避让，不替代几何分离。

GLB 打包进现有离线脚本，通过内存解析而非文件网络请求载入，因此仍支持直接打开 index.html。保留导出的独立 GLB 便于复用。

ComfyUI 使用本地现有混元3D模型生成大厅抽象雕塑，保留输入、种子、工作流和生成记录。生成雕塑与可拆分工程结构明确区分。

## 验证

- 检查 GLB 文件头、节点键、材料、尺寸、三角面数和 Blender 源文件。
- 浏览器检查模型加载、每个部件点击、拆解/恢复、单件检视、恢复全体、重新整理。
- 在桌面、窄桌面、手机画幅检查展开部件投影包围盒及边界，不只检查编号是否存在。
- 实际完成角色任务，核对错误选择、任务进度、复盘、重置、导览前后切换和地图关闭焦点。
- 保留原逻辑与代表性回归；软件渲染截图不代表实体移动GPU性能。
